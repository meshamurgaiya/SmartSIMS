# SmartSIMS

Smart Student Intelligence & Management System

## Project Overview
SmartSIMS is a web-based student management system developed using Flask, Python, MySQL, HTML, CSS, and JavaScript.

## Features
- Student Management
- Student Profile Management
- Attendance Tracking
- High Risk Student Identification
- Analytics Dashboard
- Admin Profile Management
- Password Change Module

## Technologies Used
- Python
- Flask
- MySQL
- HTML
- CSS
- JavaScript

## Project Structure
- app.py
- templates/
- static/
- database/
